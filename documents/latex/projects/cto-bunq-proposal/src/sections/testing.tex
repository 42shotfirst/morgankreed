\section{Testing}

Testing is built into every phase of the engagement, not bolted on at the end.

\begin{description}[style=nextline, leftmargin=0pt, itemsep=4pt]
\item[\textsf{Unit Testing}] Every piece of code goes through unit testing before anything else. Non-negotiable.
\item[\textsf{Automated Testing}] An automated test suite runs across all payment flows\dash standard transactions, failure scenarios, edge cases, and failover sequences across RTP, FedWire, and ACH.
\item[\textsf{Manual Testing}] A dedicated manual tester reviews everything the automated suite may not fully cover. Every gap identified is documented and resolved before moving forward.
\item[\textsf{Performance \& Load Testing}] The system is tested under production-grade transaction volumes. Throughput, latency, and reliability validated before any production connectivity is established.
\item[\textsf{Security Review}] Encryption, key management, and audit trail validation reviewed as part of Phase~3. BSA/AML and OFAC integration points tested, documented, and handed to bunq.
\needspace{6cm}
\item[\textsf{Penetration Testing}] CTO on Demand recommends engagement with an independent third-party pen tester for objectivity. Recommendations for certified providers available on request.
\item[\textsf{Certifications}] SOC2 and PCI certifications conducted by an independent certified body. CTO on Demand builds to those specifications throughout and prepares the full documentation package.
\end{description}
